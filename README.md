# 🚀 Alexey's Dev HQ

Персональная страница-полигон для обучения Git, GitHub и pull request'ов.

**Сайт:** `https://maximpushkarev79.github.io/alexey-dev-hq/` *(появится после включения GitHub Pages)*

## Что это

Тренировочный репозиторий. Здесь можно:
- Ломать что угодно (в своей ветке)
- Тренировать workflow: ветка → commit → push → PR → merge
- Видеть результат на живом сайте после каждого merge

## Как работать

1. Бери issue из вкладки Issues
2. Создай ветку: `git switch -c fix-имя-задачи`
3. Внеси изменение
4. Commit → push → открой Pull Request
5. После merge — сайт обновится автоматически

## Правила

- **Никогда** не пушить напрямую в `main`
- Одна задача = одна ветка = один PR
- Сломал — не паника, откатываем ветку
